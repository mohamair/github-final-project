# Simple Interest Calculator

A simple bash script project designed to calculate simple interest based on user inputs.

## Description
This project calculates the simple interest given the principal amount, annual rate of interest, and time period in years.

### Formula Used:
`Simple Interest = (Principal * Rate of Interest * Time) / 100`

## Inputs:
* `p`: Principal amount
* `t`: Time period in years
* `r`: Annual rate of interest

## Output:
* `Simple Interest`: The calculated interest amount
